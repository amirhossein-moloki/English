# Media Asset Licensing Policy

## Principles
1. **No Unlawful Web Scraping**: The project does not scrape HTML web pages for media assets.
2. **Official APIs & Terms**: Only official APIs with clear API terms or open media providers are queried.
3. **License Metadata Tracking**:
   Every media asset downloaded records its source provider, origin URL, license categorization, and download date.
4. **Fallback Handling**:
   When native dictionary API keys are not provided, system uses permissible open TTS providers (Edge TTS / gTTS).
